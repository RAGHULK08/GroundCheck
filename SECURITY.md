## Reporting a Vulnerability

Please report suspected vulnerabilities privately by email to Raghul K (raghul.k2023@vitstudent.ac.in) rather than opening a public issue. Include the affected file or endpoint, steps to reproduce, and the impact. You can expect an acknowledgement within 7 days.
